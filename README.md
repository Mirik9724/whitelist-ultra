# Whitelist Ultra

### Plugin for MC Bukkit, Spigot (and forks), Paper, Purpur, and Folia

### Whitelist works with nicknames (without UUID) and is case-sensitive.

## Permissions & Commands:

### **/wlu add** - Add a player to the whitelist

**Permission**: `whitelist-ultra.add`

### **/wlu remove** - Remove a player from the whitelist

**Permission**: `whitelist-ultra.remove`

### **/wlu check** - Check if a player is on the whitelist

**Permission**: `whitelist-ultra.check`

### **/wlu list** - Display the whitelist

**Permission**: `whitelist-ultra.list`

### **/wlu reload** - Reload the plugin

**Permission**: `whitelist-ultra.reload`

### **whitelist-ultra.admin** - Full permissions for all actions

---

## Translations

In the file **"whitelist-ultra/messages.yml"**, you can customize your translations.

The plugin supports standard Minecraft color codes such as **\&a** and others, as well as **MiniMessage gradients**.
[Click here for MiniMessage gradient examples](https://www.birdflop.com/resources/rgb/).
